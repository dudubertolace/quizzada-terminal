# Quiz de Futebol 

Quiz de perguntas e respostas sobre futebol, desenvolvido em Dart e executado pelo terminal.

## Como executar

1. Tenha o Dart SDK instalado.
2. Abra a pasta do projeto no terminal.
3. Execute o comando:

dart run

4. Digite seu nome e escolha a dificuldade para começar a jogar.

## Bônus implementados

- **Filtro por dificuldade:** permite escolher entre perguntas fáceis, difíceis ou todas as perguntas.
- **Embaralhamento das alternativas:** as alternativas são embaralhadas aleatoriamente a cada partida.

## Como adicionar perguntas

Para adicionar novas perguntas, basta incluir um novo `Map` na lista `dadosPerguntas`, no arquivo `lib/dados_perguntas.dart`.
